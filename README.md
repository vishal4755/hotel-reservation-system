# 🏨 Hotel Reservation System

A console-based Hotel Reservation System built with Java and JDBC.

## 🛠️ Tech Stack
- Java
- JDBC
- MySQL
- HikariCP (Connection Pooling)
- Maven

## 📦 Features
- Room Management (Add, Update, Delete)
- Guest Registration & Search
- Room Booking with Availability Check
- Check-in / Check-out Processing
- Auto Bill Generation
- Payment Tracking

## 🏗️ Architecture
- DAO Design Pattern
- Service Layer
- Transaction Management
- PreparedStatement (SQL Injection Prevention)

## ⚙️ Setup
1. Create MySQL database `grand_hotel`
2. Run SQL schema script
3. Update `db.properties` with your credentials
4. Run `Main.java`
